# About BotAppStore.com — Grok Bot Templates & Runtimes

Canonical page: https://botappstore.com/about.html

BotAppStore.com is a storefront for task-specialized Grok Bot agent templates and the license-gated local runtimes that ship with them. It is run by AIguy.

## Who runs it

BotAppStore.com is operated by AIguy. The same team runs the license service that issues and verifies BotAppStore licenses, and the sister storefront CoinLoader.com.

## What is sold

- **Grok Bot templates:** 1-click agent templates with setup and task skills that run inside your own isolated Grok Bot `/workspace` Linux sandbox.
- **License-gated local runtimes:** a standalone Python 3.10+ single-file command-line tool for each bot (standard library only, `--json` / `--markdown` output) that runs on your own machine, in CI, or in a terminal. Runtime downloads require your license key and are published with SHA-256 pins.
- **Bundles:** multi-bot packs where one license code unlocks every included bot.

There are 15 live listings: one free web text extractor and paid bots priced from $19 to $49. Every paid license is a one-time USD price with up to 3 workspace-reset rebinds and no subscription. Several bots are screening aids that flag issues for human review; they are not legal, compliance or certification determinations.

## How payment works

Pay by card, Apple Pay or Google Pay on Stripe's hosted checkout page. The payment returns a license code (`wcl_...`) after checkout. Full agent-facing steps are in [llms.txt](https://botappstore.com/llms.txt).
