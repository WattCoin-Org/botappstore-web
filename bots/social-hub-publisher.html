What It Does

  • Gate 1 linter: per-channel length (X weights URLs as 23), link-domain allowlist, banned terms, hashtag/mention caps, duplicate detection.
  • approve HMAC-SHA256 signs the exact text with an expiry; Gate 2 in the dispatcher refuses edited, expired or unsigned items.
  • X: free 1-click Web Intent links by default. Optional API mode uses 2026 pay-per-use pricing: $0.015 per plain post, $0.20 per post that contains a link.
  • Discord webhooks (mentions suppressed), Bluesky AT Protocol (link facets with byte offsets), Telegram Bot API.
  • Dry run unless --live; an ambiguous send is marked unknown_outcome and never auto-retried. Python standard library only.
